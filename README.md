# DS230 Final Project: Online News Popularity Prediction

This repository contains the code structure for the DS230 Winter 2026 final project using the **Online News Popularity** dataset. The current implementation focuses on **Task A: classification**: predicting whether an article is popular or not popular based on a median-share threshold.

Part B, the regression task, is not completed yet and is marked as a TODO in the repository structure.

## Project objective

The project analyzes article-level features from the Online News Popularity dataset and develops machine-learning models for:

1. **Task A — Classification:** predict whether an article is popular or not popular.
2. **Task B — Regression:** predict article shares or log-transformed shares. *(Pending)*

The repository is organized to support reproducibility, modular code, model comparison, explainability, robustness testing, and dashboard development.

## Data setup

Download the Online News Popularity dataset and place the CSV file here:

```text
data/raw/OnlineNewsPopularity.csv
```

The script assumes this path by default.

## Environment setup

Create and activate a virtual environment, then install the required packages:

```bash
python -m venv .venv
source .venv/bin/activate   # Mac/Linux
# .venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

## How to run Task A classification

Run the modular script from the project root:

```bash
python scripts/run_task_a_classification.py
```

This script will:

1. load and clean the dataset,
2. create engineered features,
3. define the median-share classification target,
4. split the data before preprocessing to avoid leakage,
5. log-transform skewed features after the split,
6. perform feature selection on the training data only,
7. scale selected features using `RobustScaler`,
8. train and compare classification models,
9. save results, selected features, figures, and fitted artifacts.

## Notebook

The original notebook work is preserved in:

```text
notebooks/01_task_a_classification.ipynb
```

The notebook contains EDA, feature engineering, classification models, PCA comparison, ROC/PR/calibration curves, SHAP analysis, and robustness testing.
